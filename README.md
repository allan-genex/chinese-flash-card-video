# 🇸🇬 PSLE 小六华文闪卡短视频生成器 (Primary 6 Chinese Flashcard Video Studio)

一套专为新加坡小学六年级学生、家长及华文教师设计的**考纲生字闪卡短视频生成与互动学习系统**。支持在**手机浏览器**（iPhone / iPad / Android）与**电脑端**直接运行，一键生成高质量短视频（TikTok / YouTube Shorts / 小红书 / 视频号格式）及互动答题。

---

## 🌟 核心功能特色

### 1. 🎬 闪卡短视频一键录制与导出
- **多种视频画幅比例**：
  - 📱 **9:16 竖版 (720x1280)**：专为 TikTok、YouTube Shorts、Instagram Reels、微信视频号、小红书设计。
  - 💻 **16:9 横版 (1280x720)**：适合大屏电视播放、课堂教学 PPT 投屏及 YouTube 视频。
  - 🔲 **1:1 方形 (1080x1080)**：适合 Instagram 帖子及社群分享。
- **5 款专业视觉主题**：
  - 🇸🇬 **MOE 官方考试风**：经典中国红与深蓝高对比度，标准考卷排版。
  - 🎋 **清雅翠竹风**：护眼自然绿色系，专注舒缓。
  - 🌅 **晨曦活力风**：温暖珊瑚橙与天蓝撞色，提升学习趣味。
  - 📜 **书香墨韵风**：仿古宣纸底色与印章红，典雅书卷气质。
  - 🌌 **极速夜航风**：深色深蓝夜间护眼模式。
- **动态答题倒计时流程**：
  - 思考阶段（1-5秒自定义）：展示大字汉字与标准田字格红线，进度条倒计时，引发学生思考与记忆回忆。
  - 揭晓阶段：清脆提示音，展开拼音（带声调）、英文释义、**PSLE 核心词语搭配 (搭配)** 与原汁原味新加坡语境**考试例句**。
- **纯浏览器端直录，零网络依赖**：
  - 使用 HTML5 Canvas + MediaRecorder，直接在浏览器中合成 `.webm` / `.mp4` 视频文件。
  - 导出单张卡片高清 PNG 图片，方便打印实体生字卡。

### 2. 🔊 真实语音与音效合成
- **双语语音朗读**：利用 Web Speech API 朗读标准普通话发音与考试例句。
- **Web Audio 原生合成音效**：翻卡音效（Whoosh）、答题揭晓水晶音（Chime）、倒计时滴答声（Tick）。
- **Lo-Fi 专注学习背景音乐**：程序化实时合成舒缓五声音阶背景伴奏，无需下载任何外部 MP3，录制视频时音画自动同步合轨！

### 3. 📱 手机即扫即用 (Mobile Friendly / PWA)
- **无需下载 App**：手机连接与电脑同一 Wi-Fi，用相机扫描页面上的二维码即可在手机浏览器中秒开。
- **手机触屏 3D 翻卡**：滑动与轻触翻转，支持“已掌握”与“需复习”归类统计，通关时燃放五彩纸屑庆祝。
- **支持添加到主屏幕**：iPhone Safari 点击“分享”→“添加到主屏幕”，即可变身为全屏手机应用。

### 4. 📚 完整覆盖新加坡小六 PSLE 华文考纲
- 覆盖教育部《欢乐伙伴》6A与6B全册重点生字（识写字、识读字）。
- 收录历年 PSLE 会考高频必考成语与常见易错字词。
- 每一个词语均配有 **词语搭配 (Collocations)** 和针对 PSLE Paper 2 的经典实用例句。
- 支持随时添加“自定义生字”（如每周学校听写表 Spelling List），并支持导出与导入 JSON 备份。

## 🚀 启动与使用方法

### 方式一：Windows 电脑一键启动（最推荐）
在项目文件夹中，直接双击运行：
```bash
start.bat
```
系统将自动启动服务并在默认浏览器中打开应用。

### 方式二：命令行启动
确保已安装 Node.js，在项目目录下执行：
```bash
# 启动开发服务器（允许局域网手机访问）
npm run dev -- --host
```
- **电脑访问**：在浏览器打开 [http://localhost:5173](http://localhost:5173)
- **手机访问**：在电脑界面点击右上角 **“📱 手机扫码”**，用手机相机扫码即可秒开。

## 🛠️ 技术架构
- **前端框架**：React 19 + Vite 8
- **样式美化**：Tailwind CSS v4 + Lucide Icons + Canvas-Confetti
- **渲染引擎**：原生 HTML5 Canvas 2D 高帧率渲染引擎
- **音频系统**：Web Audio API 振荡器合成器 + Web Speech API (Mandarin TTS)
- **视频录制**：MediaStream + MediaRecorder API (VP9/VP8/Opus)
- **多端响应**：完全自适应 PC、iPad、iPhone 与 Android 手机屏幕
